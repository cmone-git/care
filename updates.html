campaign App Updates & Notifications
Stay up-to-date with the latest features, improvements, and fixes in CM Dashboard.
Version 1.2.0 New Features
Aug 27, 2026
We've rolled out major additions to help streamline clinic payments and data management!
  • UPI QR Generator: Instantly generate and share branded digital payment receipts with patients via WhatsApp. Pending dues are calculated automatically.
  • Export & Backup Module: Download your filtered module data (Patients, Appointments, Transactions) directly to CSV/Excel format.
  • Admin Full Backup: Administrators can now securely download a complete JSON snapshot of the entire database.
Version 1.1.5 Improvement
Aug 15, 2026
Quality of life improvements for receptionists and staff members.
  • Searchable Dropdowns: The Patient and Therapist selection menus are now fully searchable. Type a name or mobile number to instantly find and auto-fill records.
  • Sticky Sidebar Header: The clinic logo and close button now remain sticky at the top of the mobile menu for easier navigation.
  • UI adjustments for smoother mobile scrolling on data tables.
Version 1.0.2 Security Fix
Jul 30, 2026
Backend security and optimization.
  • Firestore Query Optimization: Applied strict branch-filtering to all dynamic data loaders to comply with Firebase security rules. Staff members can now only read and interact with data strictly assigned to their branch.
  • Fixed a visual bug where the dashboard metrics occasionally loaded empty on first login.
Version 1.0.0 Launch
Jul 01, 2026
Welcome to the official launch of the Stra Care Clinic Management Dashboard!
  • Complete CRM and ERP integration for managing Patients, Appointments, and Therapists.
  • Automated Financials tracking (Total Fee, Advance, Balance, Previous OP Dues).
  • Live Dashboard with dynamic charts, calendar integrations, and daily attendance overviews.
  • Invoice generation, Letterheads, and Digital Seal capabilities.
